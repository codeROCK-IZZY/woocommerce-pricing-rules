Bulk tiers, buy-X-get-Y, sales, role prices and cart-total discounts, priced exactly to the cent.

== Description ==

* Four rule types: sale, bulk tiers (per product or mix and match), buy X get Y, and cart total.
* Limit any rule to products, categories, customer roles and a schedule; set priorities and exclusivity.
* Integer-cent engine: "$10 off" is exactly $10.00, stacked discounts compound and never go below a store-wide floor.
* Works with the classic cart and the cart and checkout blocks; orders record which rules applied.
* Quantity-discount table on product pages, original prices struck through in the cart, a "You save" line.

== Installation ==

1. Upload the plugin folder to /wp-content/plugins/ and activate it (WooCommerce must be active).
2. Add rules under WooCommerce → Pricing rules.
3. Optional settings under WooCommerce → Settings → Products → Pricing rules.
